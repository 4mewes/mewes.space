Pigeons!!!! Privacy Policy

Last updated: June 8, 2026

Pigeons!!!! is a Chrome extension that displays animated pigeons and breadcrumbs on webpages visited by the user.

Data collection

Pigeons!!!! does not collect, transmit, sell, or share personal information, browsing history, webpage content, or user activity.

Local storage

The extension uses Chrome's local storage API only to save user preferences, including pigeon population, renderer selection, debug-zone visibility, and whether the extension is enabled. This information remains on the user's device.

Website access

The extension runs locally bundled content scripts on HTTP and HTTPS webpages solely to display and animate pigeons and breadcrumbs. Page content is not stored or transmitted.

Remote code

The extension does not download or execute remotely hosted code. All executable code and assets are bundled with the extension.

Third parties

No user data is shared with third parties.
